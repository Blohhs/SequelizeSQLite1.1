# Практическая работа: Sequelize + SQLite

Консольное приложение на Node.js, демонстрирующее минимальный цикл работы с ORM Sequelize и встраиваемой БД SQLite.

## Предметная область

Таблица **`cars`** (автомобили):

| Поле          | Тип     | Ограничения                 | Описание                       |
|---------------|---------|-----------------------------|--------------------------------|
| `id`          | INTEGER | PRIMARY KEY, AUTO_INCREMENT | Добавляется Sequelize автоматически |
| `brand`       | STRING  | NOT NULL                    | Марка автомобиля               |
| `model`       | STRING  | NOT NULL                    | Модель                         |
| `year`        | INTEGER | -                           | Год выпуска                    |
| `price`       | FLOAT   | -                           | Цена в рублях                  |
| `isAvailable` | BOOLEAN | DEFAULT true                | Доступен ли для продажи        |

## Запуск

    npm install
    npm start

Скрипт создаст файл `database.sqlite`, таблицу `cars`, добавит три записи, выведет их в консоль и закроет соединение.
